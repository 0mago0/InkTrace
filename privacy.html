InkTrace 隱私權政策

最後更新日期：2026 年 8 月 25 日

InkTrace 重視使用者的隱私。本隱私權政策說明 InkTrace 在使用過程中涉及的資料與相關處理方式。

1. 個人資料

InkTrace 不要求使用者建立帳號，亦不主動蒐集姓名、 電子郵件、電話號碼或其他可識別個人身分的資料。

2. 手寫內容

使用者可透過 InkTrace 建立手寫內容並將其轉換為 SVG。 手寫內容主要於使用者裝置上進行處理。

3. GitHub 功能

InkTrace 提供將使用者建立的內容傳送至 GitHub repository 的功能。若使用此功能，使用者需自行提供 GitHub Token 及 repository 相關設定。

相關資訊僅用於執行使用者要求的 GitHub 操作。 使用者應自行妥善保管其 GitHub Token，並可隨時於 GitHub 帳號設定中撤銷相關權限。

4. 第三方服務

當使用者主動使用 GitHub 相關功能時，資料可能依照 GitHub 的服務與隱私權政策進行處理。

5. 兒童隱私

InkTrace 不會刻意蒐集兒童的個人資料。

6. 隱私權政策變更

本政策可能因功能或服務調整而更新。 最新版本將公布於本頁面。

7. 聯絡方式

若對本隱私權政策有任何疑問，請透過 InkTrace 官方支援頁面聯絡開發者。
